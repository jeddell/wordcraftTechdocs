# Warning / Caution symbols

| File | What | Provenance |
|---|---|---|
| `Warning.wmf` | WARNING box with drop shadow | Extracted from the document owner's legacy EMEI/UHB templates (embedded in `EMEI Master Style.dot`, `AB_0000_UHB_WarningPage.dot` and others). |
| `Caution.wmf` | CAUTION box with rope border | Same source (`EMEI Master Style.dot`, `AE_0000_UHB_NotesReader.dot`). |

The Warning/Caution/Note buttons insert these in front of the Warning and Caution text. They are
compiled into the app, so they are always available; replace a file here and rebuild to change
the symbol.
