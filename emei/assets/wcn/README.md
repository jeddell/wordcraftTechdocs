# Warning / Caution symbols

Place the symbol files here (supplied by the document owner, not part of this repository's
own artwork):

- `Warning.wmf` (or `.png` / `.emf`)
- `Caution.wmf` (or `.png` / `.emf`)

The Warning/Caution/Note button inserts them in front of the Warning and Caution paragraphs.
If a file is missing, the button inserts the paragraphs and reports the missing symbol rather
than failing silently.
